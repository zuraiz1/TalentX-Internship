# ABOUT

Save your logo as a PNG file, ideally with a see-through (transparent)
background rather than a white background, so it looks clean once placed.
 
Name the file exactly:  logo.png
 
...and save it in the same folder as poster_logo_batch.py.
 
If you'd rather use a different filename, that's fine too — the tool will
ask you for it each time (see below).


# How to use
## SETUP

1. Unzip "Batch Logo Processing.zip"
2. Run "SETUP.py"
3. Run "Batch Logo Processing.py" once

---
## USE

   1. Drop posters into "To be processed"
   2. Double-click the tool, press Enter
   3. Collect your finished posters from "Finished"
